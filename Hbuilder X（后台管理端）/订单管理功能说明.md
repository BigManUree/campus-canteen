# 订单管理系统 - 功能说明

## ✅ 已实现功能

### 1. 实时轮询
- 每5秒自动刷新订单列表
- 页面加载时自动启动
- 页面卸载时自动停止

### 2. 新订单提醒
- 有新订单时自动提示
- 播放提示音（如果有音频文件）
- 手机震动
- Toast消息提示
- 红色徽章显示新订单数量

### 3. 状态筛选
- 全部订单
- 待接单（橙色）
- 制作中（蓝色）
- 待取餐（绿色）
- 每个标签显示订单数量

### 4. 订单操作
- **待接单状态**：显示"✅ 接单"按钮
- **制作中状态**：显示"✔️ 制作完成"按钮
- **待取餐状态**：显示取餐码
- **所有状态**：都可以查看详情

### 5. 扫码核销
- 点击"📷 扫码核销"按钮
- 扫描用户的取餐码
- 自动完成订单

## 🚀 使用方法

1. 登录管理端
2. 进入"订单管理"页面
3. 系统自动轮询订单
4. 有新订单时会自动提醒
5. 点击对应按钮进行操作

## 📱 完整流程

```
新订单 → 自动提醒 → 点击接单 → 制作菜品 → 点击制作完成 → 显示取餐码 → 扫码核销 → 完成
```

## 🎵 提示音配置（可选）

如需提示音效果，请将 `new-order.mp3` 文件放到 `/static/sounds/` 目录。

如果没有音频文件，系统会使用震动和Toast替代。
