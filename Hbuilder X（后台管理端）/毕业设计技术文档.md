# 微信小程序毕业设计技术文档

## 一、项目题目

**基于微信小程序的校园食堂点餐系统**

### 题目说明
本项目旨在设计并实现一个服务于校园师生的食堂点餐微信小程序，支持用户在线浏览菜品、下单、预约取餐或配送。系统需具备完整的业务流程：用户注册登录、菜品管理、购物车、订单管理、评价反馈、定位导航、音视频菜品介绍等。同时必须连接本地 MySQL 数据库服务器，支持数据的读取、浏览、修改与备份，满足毕业设计中对本地数据库、定位精度（≤100 米）、本地音视频存储播放等要求。

## 二、技术栈清单

### 2.1 前端技术
- **开发框架**: 微信小程序原生框架
- **开发工具**: 微信开发者工具（最新稳定版）
- **UI 组件库**:
  - WeUI（官方 UI）
  - ColorUI 或 Vant Weapp（可选，用于快速构建美观界面）
- **前端语言**:
  - JavaScript (ES6+)
  - WXML / WXSS / JSON

### 2.2 后端技术（Java 方案）
- **后端框架**: Java 17 + Spring Boot 3.x
- **核心依赖**:
  - spring-boot-starter-web（REST API）
  - spring-boot-starter-data-jpa（或 MyBatis-Plus）
  - mysql-connector-j
  - spring-boot-starter-security + jjwt（JWT 鉴权）
  - spring-boot-starter-validation（参数校验）
  - spring-boot-starter-cache + caffeine（缓存，可选）
  - spring-boot-starter-log4j2（日志）
  - commons-fileupload / spring-multipart（音视频上传）
- **构建工具**: Maven 或 Gradle（推荐 Maven 3.8+）
- **运行环境**: JDK 17、Spring Boot 3.x、Tomcat 10 内嵌
### 2.3 后端技术（Python 方案）
- **后端框架**: Python 3.11+ + FastAPI
- **核心依赖**:
  - fastapi + uvicorn[standard]（异步 REST API）
  - SQLAlchemy 2.x + Alembic（ORM 与迁移）
  - mysqlclient / aiomysql（MySQL 驱动）
  - python-jose[cryptography]（JWT 鉴权）
  - passlib[bcrypt]（密码哈希）
  - pydantic v2（数据校验）
  - httpx（第三方调用，可选）
  - redis + aioredis（缓存/会话，可选）
  - loguru（日志）
- **运行环境**: Python 3.11、Uvicorn、Nginx（反向代理，可选）
- **开发工具**: Poetry 或 pip + venv（推荐 Poetry）

### 2.4 数据库
- **数据库类型**: MySQL 8.0+
- **数据库管理工具**:
  - Navicat / DataGrip / MySQL Workbench
- **备份工具**:
  - mysqldump（命令行）
  - Navicat 备份任务

### 2.5 服务器环境
- **本地部署**:
  - 安装 JDK 17、MySQL 8.0
  - Spring Boot 内嵌 Tomcat 监听 `http://localhost:8080`
  - Nginx（可选）作反向代理/静态音视频托管
- **API 架构**: RESTful + JSON，统一 `/api/**` 前缀
- **多媒体存储**:
  - 本地磁盘 `server/uploads/`
  - 通过 Spring Boot 提供下载/播放接口

### 2.6 开发辅助工具
- Git + GitHub/Gitee（版本控制）
- Postman/Apifox（接口调试）
- VS Code（代码编辑器）
- Figma/PS（UI 设计）

## 三、功能模块设计

### 3.1 用户与账号模块
- 用户注册：手机号/学号注册，短信或邮箱验证
- 用户登录：账号密码 + Token 机制
- 个人信息：头像、昵称、学号、学院、口味偏好、过敏原设置
- 地址管理：宿舍/办公楼地址、定位信息、默认地址
- 权限管理：普通用户、食堂档口管理员、后台管理员

### 3.2 食堂与菜品模块
- 食堂档口管理：食堂、楼层、窗口、营业时间、服务类型（自提/配送）
- 菜品管理：
  - 菜品信息（名称、价格、库存、标签、辣度、过敏原、营养信息）
  - 菜品图片上传（最多 9 张）
  - 菜品音频/视频介绍（本地存储 + 小程序端播放）
  - 菜品上下架、库存预警
- 菜品展示：
  - 首页推荐、热销榜、新品、菜品视频展示
  - 分类浏览（主食、小炒、饮品、甜品等）
  - 档口筛选、菜品搜索、价格/销量排序

### 3.3 点餐与订单模块
- 购物车：添加菜品、数量调整、口味备注、跨档口拆单提示
- 下单流程：
  - 取餐方式：自提 / 配送
  - 预约时间选择
  - 优惠券 / 满减 / 组合套餐
  - 支付方式：微信支付（模拟）或现金到付
- 订单管理：
  - 状态流转：待确认 → 制作中 → 待取餐 / 配送中 → 已完成 → 评价
  - 取消/退款申请、订单催单
  - 取餐码生成、核销
- 物流与定位：
  - 自提点定位与导航，精度 100 米内
  - 配送路径规划，实时位置更新（可选）

### 3.4 评价与互动模块
- 菜品评价：评分、文字、图片、音/视频评价
- 档口评价：服务态度、出餐速度
- 客服与消息：
  - 订单消息提醒（制作完成、配送提醒）
  - 系统公告、优惠活动推送
  - 在线客服/无人客服问答

### 3.5 数据与增值模块
- 收藏、浏览历史、再次购买
- 数据看板：菜品销量、时间段热度、用户偏好
- 活动管理：优惠券、秒杀、套餐
- 食堂排队信息（可选）：实时排队人数、预计等待时间

## 八、定位与音视频实现

### 8.1 定位
- 小程序端使用 `wx.getLocation`（`type: 'gcj02'`）获取用户当前位置
- 使用 `wx.chooseLocation` 让用户选择取餐点/配送点
- 后端存储经纬度，使用 Haversine 公式计算距离，确保精度 ≤100m

### 8.2 地图与导航

### 8.3 音视频本地化

- 小程序端使用 `video`、`audio` 组件播放

## 十四、后端分层设计与关键实现

### 14.1 分层结构
```
server/
├── src/main/java/com/campus/canteen
│   ├── CampusCanteenApplication.java
│   ├── config/           # CORS、Swagger、文件存储、缓存配置
│   ├── security/         # JWT 过滤器、用户详情、加密
│   ├── controller/       # REST 接口层（DTO 入参/出参）
│   ├── service/
│   │   ├── dto/          # 业务 DTO、VO
│   │   ├── impl/         # 具体实现
│   ├── domain/
│   │   ├── entity/       # JPA Entity 或 MyBatis-Plus 实体
│   │   └── mapper/       # Repository/Mapper 接口
│   ├── common/
│   │   ├── exception/    # 全局异常、错误码
│   │   ├── enums/        # 常量、字典
│   │   └── util/         # 工具类（加密、距离计算等）
│   └── storage/          # 媒体文件服务
└── src/main/resources
    ├── application.yml
    └── mapper/*.xml      # 若使用 MyBatis
```

### 14.2 核心模块说明
- **认证模块**：使用 Spring Security + JWT，登录成功后生成 `Authorization: Bearer <token>`，所有受保护接口在过滤器中解析 token、加载用户信息、校验角色。
- **文件存储模块**：基于 `MultipartFile`，将菜品音/视频保存到 `media.upload-path`，数据库仅存相对路径；提供 `/api/media/{id}` 接口输出流并设置 `Content-Type`。
- **定位模块**：封装 `LocationService`，持久化经纬度；提供距离计算工具 `GeoUtil.calculateDistance(lat1, lng1, lat2, lng2)`。
- **缓存与热点**：菜品列表、档口信息可使用 `@Cacheable` + Caffeine，减少数据库压力；下单成功后按需失效缓存。
- **日志与监控**：Log4j2 记录 `info`、`warn`、`error`，结合 Spring Boot Actuator 监控健康状态。

### 14.3 关键业务流程
1. **下单流程**：登录 → 选择菜品 → 购物车 → 创建订单（校验库存、扣减库存、生成取餐码）→ 返回订单详情 → 生产端接单（Web/客户端）→ 状态更新。
2. **菜品媒体上传**：管理员在后台上传图片/音视频 → 服务端保存文件 → 数据表 `dish_media` 记录类型、时长、大小 → 小程序通过 URL 播放。
3. **定位导航**：订单含自提/配送地址 → 小程序请求 `/api/location/canteen/{id}` → 根据经纬度调用 `wx.openLocation` 或第三方地图 SDK。

### 14.4 Python（FastAPI）分层结构补充
- **依赖注入**：使用 FastAPI 的 `Depends` 注入数据库 Session、当前用户、缓存客户端。
- **数据库会话**：在中间件中创建/关闭 SQLAlchemy Session，确保请求级生命周期。
- **认证中间件**：基于 `Authorization: Bearer <token>` 的 JWT 解码，返回 `CurrentUser` 依赖。
- **静态文件/媒体**：`StaticFiles` 挂载 `/media` 到本地上传目录；上传接口使用 `UploadFile` 写入磁盘并记录元数据。
- **异常处理**：全局 `HTTPException` 与自定义业务异常统一返回 `{code, message}`。

## 十六、关键业务流程描述

### 16.1 点餐流程（顺序）
1. 用户登录并授权定位。
2. 浏览菜品、查看音视频介绍。
3. 加入购物车，填写备注、选择取餐方式。
4. 提交订单 → 服务端校验库存、生成订单、写入数据库。
5. 若选择配送，服务端根据地址经纬度匹配距离最近的骑手/档口（扩展）。
6. 档口确认并开始制作，状态推送至用户端。
7. 用户凭取餐码到指定窗口或等待配送到达。
8. 订单完成后发起评价，更新菜品评分。

### 16.2 音视频处理流程
1. 管理端上传菜品音/视频（支持 MP4、MOV、MP3、WAV）。
2. Spring Boot 保存原始文件并记录 `media_id`。
3. 小程序请求 `/api/dish/media/{mediaId}`，后端返回带 `Content-Disposition` 的流。
4. 前端使用 `<video>` 或 `<audio>` 组件播放，可开启 `autoplay`、`poster`。
5. 若需离线，可在小程序端调用 `wx.downloadFile` 缓存到本地。

### 16.3 定位流程
1. 首次进入下单页调用 `wx.getLocation` 获取当前位置。
2. 选择地址时调用 `wx.chooseLocation`，拿到精度 ≤100 米的经纬度。
3. 前端将经纬度提交至服务器，写入 `user_addresses` 和订单配送字段。
4. 后端通过距离算法计算配送费用或推荐最近食堂。
5. 用户点击“导航取餐”时调用 `wx.openLocation`，传入档口经纬度。
