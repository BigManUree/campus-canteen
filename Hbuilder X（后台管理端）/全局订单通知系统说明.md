# 全局订单通知系统说明

## 功能概述

全局订单通知系统可以在管理员登录后，无论在哪个页面都能实时收到新订单提醒。

## 实现原理

### 1. 全局轮询机制
- 在 `App.vue` 中实现全局订单轮询
- 每5秒自动检查一次待接单订单数量
- 检测到新订单时立即弹出通知

### 2. 管理员状态检测
- 自动检测用户是否为管理员（role === 'admin'）
- 只有管理员登录后才启动轮询
- 退出登录或切换到非管理员账号时自动停止轮询

### 3. 多重提醒方式
- **弹窗提醒**：显示订单号和金额，可直接跳转到订单管理页面
- **Toast提示**：轻量级提示，不打断用户操作
- **震动提醒**：三次短震动，引起注意
- **提示音**：播放音频文件（如果存在）

## 使用方法

### 管理员端
1. 使用管理员账号登录
2. 系统自动启动全局订单监听
3. 有新订单时会自动弹出提醒
4. 点击"去处理"可直接跳转到订单管理页面

### 测试功能
访问测试页面：`/pages/admin/test-notification`

测试页面功能：
- 查看当前管理员状态和轮询状态
- 模拟新订单通知
- 测试震动功能
- 测试提示音功能
- 查看实时日志

- 建议使用1-3秒的清脆铃声

## 技术细节

### 轮询间隔
- 全局轮询：5秒
- 页面内轮询：5秒（仅在订单管理页面）

### 新订单检测逻辑
```javascript
// 检测待接单订单数量变化
const pendingOrders = orders.filter(o => o.order_status === 0)
const currentCount = pendingOrders.length

// 如果数量增加，说明有新订单
if (lastCount > 0 && currentCount > lastCount) {
    const newCount = currentCount - lastCount
    showNotification(newCount)
}
```

### 通知触发条件
1. 管理员已登录
2. 待接单订单数量增加
3. 不是首次加载（lastCount > 0）

## 优化建议

### 1. 添加提示音
在 `/static/sounds/` 目录下添加 `new-order.mp3` 文件，可以从以下网站获取：
- https://freesound.org/
- https://mixkit.co/free-sound-effects/
- https://www.zapsplat.com/

### 2. 调整轮询间隔
如果需要更快的响应速度，可以在 `App.vue` 中修改：
```javascript
// 将5000改为更小的值（单位：毫秒）
this.orderPollingTimer = setInterval(() => {
    this.checkNewOrders()
}, 3000) // 改为3秒
```

### 3. 使用 WebSocket（推荐）
如果后端支持 WebSocket，可以替换轮询机制，实现真正的实时推送：
- 更低的延迟
- 更少的服务器请求
- 更好的用户体验

## 常见问题

### Q: 为什么没有收到通知？
A: 请检查：
1. 是否使用管理员账号登录
2. 是否有新的待接单订单（order_status === 0）
3. 查看控制台是否有错误信息
4. 使用测试页面检查轮询状态

### Q: 通知太频繁怎么办？
A: 可以增加轮询间隔，或者添加防抖逻辑

### Q: 提示音不播放？
A: 
1. 检查 `/static/sounds/new-order.mp3` 文件是否存在
2. 检查文件格式是否正确
3. 系统会自动降级使用震动提醒

### Q: 在订单管理页面收到重复通知？
A: 已优化，订单管理页面只更新列表，不显示通知弹窗
