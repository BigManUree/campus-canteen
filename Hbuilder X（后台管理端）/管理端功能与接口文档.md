\## 基础说明



\### Base URL

\```

开发环境: http://localhost:8000/api

生产环境: 根据实际部署地址配置

\```



\### 认证方式

所有接口都需要在请求头中携带 JWT Token：

\```

Authorization: Bearer {token}

\```



\### 权限说明

\- `user`: 普通用户

\- `canteen_admin`: 档口管理员（可管理自己档口的订单、菜品）

\- `sys_admin`: 系统管理员（全部权限）



\### 响应格式

\- **成功响应**: HTTP 状态码 200-299，响应体为 JSON 格式

\- **错误响应**: HTTP 状态码 400+，响应体格式：

\```json

{

  "detail": "错误信息"

}

\```



\### 分页响应格式

\```json

{

  "items": [...],

  "total": 100,

  "page": 1,

  "page_size": 20

}

\```

**响应**:

\```json

{

  "token": "jwt_token_string",

  "expireIn": 7200,

\## 订单管理



\### 1. 获取订单列表

**GET** `/api/order/list`



**需要认证**: ✅ (管理员)



**查询参数**:

\- `page` (int, 可选): 页码，默认1

\- `page_size` (int, 可选): 每页数量，默认20

\- `order_status` (int, 可选): 订单状态筛选（0-待确认，1-制作中，2-待取餐，3-配送中，4-已完成，5-已取消）

\- `pay_status` (int, 可选): 支付状态筛选（0-未支付，1-已支付）

\- `order_no` (string, 可选): 订单号搜索

\- `start_date` (string, 可选): 开始日期（YYYY-MM-DD）

\- `end_date` (string, 可选): 结束日期（YYYY-MM-DD）

\- `canteen_id` (int, 可选): 档口ID筛选（档口管理员只能看自己档口）



**响应**: 分页格式

\```json

{

  "items": [

​    {

​      "order_id": 1,

​      "order_no": "ORDER20240101001",

​      "user_id": 1,

​      "canteen_id": 1,

​      "order_type": "pickup",

​      "order_status": 1,

​      "pay_status": 1,

​      "total_amount": 30.0,

​      "discount_amount": 0.0,

​      "pay_amount": 30.0,

​      "pickup_code": "A001",

​      "create_time": "2024-01-01T10:00:00",

​      "user": {

​        "nickname": "用户昵称",

​        "phone": "13900139000"

​      },

​      "canteen": {

​        "canteen_name": "档口名称"

​      }

​    }

  ],

  "total": 100,

  "page": 1,

  "page_size": 20

}

\```



**功能说明**:

\- 订单列表展示

\- 支持多条件筛选和搜索

\- 分页加载

\- 档口管理员自动筛选自己档口的订单



\### 2. 获取订单详情

**GET** `/api/order/detail/{order_id}`



**需要认证**: ✅ (管理员)



**路径参数**:

\- `order_id` (int): 订单ID



**响应**: 完整的订单对象（包含订单项、用户信息、档口信息等）



**功能说明**:

\- 订单详情查看

\- 查看订单项明细

\- 查看用户信息和地址

\- 查看支付信息



\### 3. 更新订单状态

**PUT** `/api/order/status/{order_id}`



**需要认证**: ✅ (管理员)



**路径参数**:

\- `order_id` (int): 订单ID



**请求体**:

\```json

{

  "order_status": 2  // 订单状态：0-待确认，1-制作中，2-待取餐，3-配送中，4-已完成，5-已取消

}

\```



**响应**: 更新后的订单对象



**错误码**:

\- `403`: 需要管理员权限

\- `404`: 订单不存在

\- `400`: 订单状态不允许修改



**功能说明**:

\- 订单状态流转

\- 状态按钮操作

\- 状态变更历史记录（可选）



\### 4. 验证取餐码

**POST** `/api/order/verify/{order_id}`



**需要认证**: ✅ (管理员)



**路径参数**:

\- `order_id` (int): 订单ID



**查询参数**:

\- `pickup_code` (string, 必填): 取餐码



**响应**:

\```json

{

  "success": true,

  "message": "取餐码验证成功"

}

\```



**错误码**:

\- `400`: 取餐码错误

\- `404`: 订单不存在



**功能说明**:

\- 取餐码验证界面

\- 验证成功后自动更新订单状态为"已完成"

  "name": "菜品名称",         // 必填

  "calorie": 300,            // 卡路里（可选）

  "images": ["url1", "url2"], // 图片URL列表（可选）

\- 音视频上传（可选）

**功能说明**:

  - 订单号、下单时间、用户昵称、用户手机号、档口名称
  - 订单类型、订单状态、支付状态、取餐码
  - 商品总额、优惠金额、实付金额
  - 配送地址、备注、预约时间
  - 订单明细（菜品名称、数量、单价、小计）

**导出实现**:
```javascript
// Vue 2 + Element UI 示例
async exportOrders(params) {
  try {
    const response = await axios({
      method: 'GET',
      url: '/api/export/orders',
      params: params,
      responseType: 'blob', // 重要：指定响应类型为blob
      headers: {
        'Authorization': `Bearer ${token}`
      }
    })
    
    // 创建下载链接
    const blob = new Blob([response.data])
    const url = window.URL.createObjectURL(blob)
    const link = document.createElement('a')
    link.href = url
    
    // 从响应头获取文件名
    const contentDisposition = response.headers['content-disposition']
    let filename = 'orders.xlsx'
    if (contentDisposition) {
      const filenameMatch = contentDisposition.match(/filename="?(.+)"?/)
      if (filenameMatch) {
        filename = decodeURIComponent(filenameMatch[1])
      }
    }
    
    link.setAttribute('download', filename)
    document.body.appendChild(link)
    link.click()
    document.body.removeChild(link)
    window.URL.revokeObjectURL(url)
    
    this.$message.success('导出成功')
  } catch (error) {
    this.$message.error('导出失败')
    console.error('导出失败:', error)
  }
}
```

**页面元素**:
- 日期范围选择器
