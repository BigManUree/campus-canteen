## 🔧 API接口说明

### 退款相关API

```javascript
// 创建退款申请（用户端）
adminApi.refundCreate(data)

// 获取退款详情
adminApi.refundGetDetail(refund_id)

// 批准退款（管理员）
adminApi.refundApprove(refund_id, { admin_remark })

// 拒绝退款（管理员）
adminApi.refundReject(refund_id, { admin_remark })

// 获取退款统计（管理员）
adminApi.refundGetStatistics({ days: 30 })

// 管理端退款列表（旧接口兼容）
adminApi.refundAdminList(params)
adminApi.refundStatistics()
```

### 通知相关API

```javascript
// 获取通知列表（支持筛选）
adminApi.notificationGetList(params)

// 获取未读通知数量
adminApi.notificationGetUnreadCount()

// 标记通知为已读（支持批量）
adminApi.notificationMarkAsRead({ notification_ids })

// 删除通知
adminApi.notificationDeleteOne(notification_id)

// 旧接口（保留兼容）
adminApi.notificationList(params)
adminApi.notificationMarkRead(message_id)
adminApi.notificationMarkAllRead()
adminApi.notificationDelete(message_id)
```

## 📱 使用说明

### 1. 退款管理页面

#### 访问路径
```
/pages/admin/refunds/index
```

#### 主要功能
1. **查看退款列表**：显示所有退款申请，支持分页
2. **筛选退款**：按状态、订单ID、用户ID筛选
3. **查看统计**：查看退款总数、金额、原因分类
4. **审批退款**：批准或拒绝退款申请
5. **实时更新**：收到新退款申请时自动刷新

#### 操作流程
1. 进入退款管理页面
2. 查看待处理退款（黄色标记）
3. 点击"批准退款"或"拒绝退款"
4. 填写备注（可选）
5. 确认操作
6. 查看结果（批准成功显示成功弹窗）

---

### 2. 通知中心页面

#### 访问路径
```
/pages/admin/notifications/index
```

#### 主要功能
1. **查看通知列表**：显示所有通知，支持分页
2. **筛选通知**：按状态（未读/已读）筛选
3. **查看统计**：查看通知总数、未读数、分类统计
4. **管理通知**：标记已读、删除通知
5. **发送通知**：发送给全体用户或指定用户
6. **实时更新**：收到新通知时自动刷新

#### 操作流程
1. 进入通知中心页面
2. 查看未读通知（红色标记）
3. 点击通知查看详情（自动标记已读）
4. 批量操作：勾选多个通知，批量标记已读或删除
5. 发送通知：点击"发送通知"，选择对象，输入内容

---

### 3. 全局通知系统

#### 自动启动条件
- 管理员已登录（admin_token存在）
- 用户角色为管理员（admin、canteen_admin、sys_admin）

#### 通知触发条件
- **新订单**：有新的待接单订单（order_status=0）
- **新退款**：有新的待处理退款申请（status=pending）

#### 通知方式
1. **弹窗提醒**：显示详细信息，可点击"去处理"跳转
2. **Toast提示**：简短提示，3秒后自动消失
3. **震动提醒**：连续震动3次
4. **提示音**：播放通知音效（需要音频文件）

#### 关闭通知
- 退出登录时自动停止
- 应用进入后台时自动停止
- 应用返回前台时自动恢复

## 🔔 WebSocket事件说明

### 事件类型

```javascript
// 退款相关
'ws:refund_request'    // 新退款申请
'ws:refund_result'     // 退款审批结果

// 订单相关
'ws:new_order'         // 新订单
'ws:order_status_changed' // 订单状态变更

// 通知相关
'ws:notification'      // 通用通知
```

### 监听示例

```javascript
// 在页面中监听
onShow() {
    uni.$on('ws:refund_request', this.handleRefundRequest)
}

onHide() {
    uni.$off('ws:refund_request', this.handleRefundRequest)
}

methods: {
    handleRefundRequest(data) {
        console.log('收到退款申请:', data)
        // 刷新数据
        this.fetchList()
    }
}
```
