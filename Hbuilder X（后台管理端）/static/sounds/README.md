# 提示音文件说明

## 需要的音频文件

请将以下音频文件放置在此目录：

1. **notification.mp3** - 通用通知提示音（新订单、退款申请等）
   - 建议：清脆的铃声或提示音
   - 时长：1-3秒
   - 格式：MP3
   - 用途：新订单通知、退款申请通知

2. **success.mp3** - 操作成功提示音
   - 建议：轻快的成功音效
   - 时长：0.5-1秒
   - 格式：MP3

## 临时方案

如果暂时没有音频文件，系统会自动使用以下替代方案：
- ✅ 使用系统震动提醒（连续3次重震动）
- ✅ 使用Toast消息提示
- ✅ 使用Modal弹窗提示

## 获取音频文件

你可以从以下网站获取免费音效：
- https://freesound.org/
- https://mixkit.co/free-sound-effects/
- https://www.zapsplat.com/

或者使用在线工具生成简单的提示音。

## 当前通知功能

系统已实现全局实时通知功能：
- 🔔 新订单通知：用户下单支付成功后立即提醒
- 💰 退款申请通知：用户申请退款后立即提醒
- 📱 支持在任何管理端页面接收通知
- ⏱️ 每5秒自动检查一次新通知
- 🔊 音频提示 + 震动提醒 + 弹窗提示
